# Sign-Up Form

## Overview

The Sign-Up Form is a web-based registration page built to practice intermediate HTML and CSS concepts. The project focuses on creating a structured form layout based on a provided design reference, with an emphasis on styling, form validation, and user interaction.

The page features a background image, custom branding, and a registration form with multiple input fields.

## Features

- **Registration Form:** Input fields for user information and account details.
- **Form Validation:** Uses HTML form validation to check required fields and input formats.
- **Password Validation:** Highlights invalid password inputs using CSS pseudo-classes.
- **Interactive Styling:** Provides visual feedback when input fields are selected.
- **Custom Design:** Background imagery, custom fonts, and styled form elements.
- **Submit Button:** Styled account creation button.

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and form elements |
| CSS3 | Layout, styling, and form validation |

## Getting Started

## Learning Objectives

This project was developed to practice and demonstrate:

- Structuring HTML forms and input elements.
- Using CSS Flexbox for page layout.
- Styling form elements and buttons.
- Implementing HTML form validation.
- Using CSS pseudo-classes such as `:focus` and `:user-invalid`.
- Working with custom fonts and background images.
- Recreating a design reference using HTML and CSS.
